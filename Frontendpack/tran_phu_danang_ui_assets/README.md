# Trần Phú Đà Nẵng – UI Assets Pack

Bộ asset/component này được tách từ phương án dashboard đã chọn.

## Cấu trúc
- 01_branding: logo, lockup tên trường, title hệ thống, header wave
- 02_sidebar: sidebar trái đầy đủ
- 03_controls: top controls và các chip chức năng
- 04_camera_cards: camera card vi phạm / bình thường / offline
- 05_incident_cards: sự cố đỏ / cảnh báo / vi phạm tài liệu
- 06_table: bảng dữ liệu danh sách thí sinh / sự cố
- 07_badges_icons: badge/tag và bộ icon reference
- 08_patterns: SVG pattern Đà Nẵng (skyline, cầu, wave, watermark)
- 09_reference: ảnh UI tổng thể + component board

## Lưu ý cho coding agent
1. Không ghép screenshot thành UI production.
2. Recreate toàn bộ thành component thật theo stack hiện tại.
3. Giữ nguyên backend/API/logic nếu đây là dự án đang chạy.
4. Sử dụng logo gốc của trường từ `school-logo-original.png`.
5. Danang motifs chỉ làm điểm nhấn, không lấn bố cục camera.
